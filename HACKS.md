# Hacks & Workarounds

This file records non-obvious build constraints that must survive upstream merges.

## Go c-archive linking

The Packet Tunnel extension calls the C API generated by `go build -buildmode=c-archive`.

Do **not** add `libgolocationspoofer.a` to the target's source/resource list. XcodeGen can otherwise copy the archive into the .appex bundle, which is invalid for distribution and also undesirable in the unsigned IPA.

The current `project.yml` links the prebuilt archive with:

- `LIBRARY_SEARCH_PATHS = $(PROJECT_DIR)/GoSpoofer/build`
- `OTHER_LDFLAGS = -lgolocationspoofer`
- `HEADER_SEARCH_PATHS = $(PROJECT_DIR)/GoSpoofer`

CI builds the archive before running XcodeGen. This replaces the old manual `project.pbxproj` patch and keeps `project.yml` as the source of truth.

## Unsigned IPA

CI archives with code signing disabled, then verifies that the app and Packet Tunnel executables are arm64 and unsigned, and rejects embedded provisioning profiles, static archives and duplicate IPA outputs.

A later sideload/signing step still needs compatible Network Extension and App Group entitlements.
